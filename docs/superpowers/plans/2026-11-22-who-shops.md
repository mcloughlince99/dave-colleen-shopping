# Who Shops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** Tag each item C / D / Both and filter the list to "Mine" / "Dave's" / "Everything".
**Architecture:** Add a `who` field to items in the existing single Firestore doc; filtering is view-only.
**Tech Stack:** Plain HTML + JS, Firebase compat SDK (no build step).
**Spec:** `docs/superpowers/specs/2026-11-22-who-shops-design.md`

## Global Constraints
- `who` values: `colleen` | `dave` | `both`; missing = `both`.
- Tap cycle: colleen → dave → both → colleen.
- Filter remembered in `localStorage` key `grocery-filter` (`all` | `me` | `other`).
- Emails: colleen = mcloughlince@gmail.com, dave = dhbednarz@gmail.com.

## Review Focus
- Old items with no `who` must show under every filter (treated as `both`).
- A name with `"`, `'`, `\` or `<` must not break buttons or the page.
- Store with zero visible items under a filter still shows its header + add box.
- Adding an item while filtered to "Dave's" should not vanish confusingly — new item = `both`, so it stays visible.
- Counts ("x of y") must match the visible items.
